# Database Project – Banking System

### Системийн тайлбар
Энэхүү төсөл нь **Banking System** системийн өгөгдлийн санг зохион байгуулсан болно. 
Систем нь дараах үндсэн хүснэгтүүдээс бүрдэнэ:
* **Table 1: clients** – Харилцагчийн мэдээлэл
* **Table 2: accounts** – Дансны мэдээлэл
* **Table 3: transactions** – Гүйлгээний мэдээлэл
* **Table 4: loans** – Зээлийн мэдээлэл

Эдгээр хүснэгтүүд нь хоорондоо **Foreign Key** холбоотой бөгөөд бодит системийн өгөгдлийг хадгалах зориулалттай.

###  4-р хэсэг: Онол (Security)

1. **DECIMAL vs INT:** Санхүүгийн тооцоололд нарийвчлал маш чухал тул бутархай тоо хадгалах чадвартай `DECIMAL` төрлийг ашигладаг. `INT` нь мөнгөн дүнг хадгалахад тохиромжгүй.
2. **Foreign Key:** Байхгүй тохиолдолд харилцагчгүй данс, эзэнгүй гүйлгээ үүсэх зэргээр өгөгдлийн сангийн логик холбоо алдагдана.
3. **Plain Text Password:** Нууц үгийг шууд хадгалах нь халдлагын үед бүх мэдээллийг алдах эрсдэлтэй. Заавал Hash хийх шаардлагатай.
